The polling trigger lives on this element and only while the run is `pending`, so a finished run stops the poll by virtue of what came back: there is no timer to cancel and no client-side state to get out of step with the row. `hx-swap="outerHTML"` because the element replaces itself. Same trick as `_extraction.html`. `cluster` is a `jfl_web.capabilityclusters.ClusterView`, or None when the page did not look one up (an error re-render) -- in which case only the button shows, because "no run yet" is a claim this template cannot make. Nothing here is applied silently: every proposal carries accept, rename and reject, and the profile changes only when one of them is pressed. #}
