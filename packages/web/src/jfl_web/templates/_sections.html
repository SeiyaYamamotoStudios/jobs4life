{# The one collapsible section component. Every panel on every screen uses it. `
`/`` and nothing else: native, keyboard-accessible, found by the browser's own in-page search, and **fully working with JavaScript switched off**. With no JS the sections open and close exactly as they do with it; the only thing lost is that the choice is not remembered between visits. That is the whole of the progressive enhancement here. `sec` is a `jfl_web.sections.Section`. Everything it carries was decided in Python -- whether the section starts open, what its count summary says, and whether it has changed since the user last looked -- so this file contains no rules, only markup. See `docs/ui-sections.md` for the contract and `jfl_web.sections` for the defaults. `data-section` and `data-default-open` are what `static/sections.js` posts back on toggle. `data-default-open` is what this page would have rendered had the user never touched this section, which is what makes "they went against the default" measurable later.
