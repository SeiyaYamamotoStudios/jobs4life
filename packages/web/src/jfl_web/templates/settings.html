Email digest

Once a day, an email of the new and returned jobs on the boards you watch that match your saved filter — the same filter and per-board exceptions as Changes. If a board could not be checked it says so, so a quiet inbox never means “we couldn’t look”. If nothing else is sent for a week you get one short note that it is still running. Nothing from your CV, applications or scores is ever in it, and it has no tracking. Reading it does not mark anything on Changes as seen.
